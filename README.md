# 🏓 Pong Game – Python Turtle

A classic two-player Pong game built using Python and the Turtle graphics module.

## 🎮 About the Project

This project recreates the classic Pong arcade game, where two players control paddles to hit a moving ball and score points against each other.

The game uses Python's Turtle module for graphics, keyboard event handling, movement and collision detection.

## ✨ Features

- Two-player gameplay
- Keyboard-controlled paddles
- Ball movement and bouncing mechanics
- Paddle and wall collision detection
- Automatic score tracking
- Increasing ball speed during gameplay
- Ball reset after a player misses

## 🕹️ Controls

| Player | Move Up | Move Down |
|---|---|---|
| Left Player | W | S |
| Right Player | ↑ Up Arrow | ↓ Down Arrow |

## 🛠️ Technologies Used

- Python 3
- Turtle Graphics
- Object-Oriented Programming (OOP)
